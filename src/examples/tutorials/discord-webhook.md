# How to create a Discord webhook for Aquarium ?

Need to send notifications to your team when a task is created, updated or completed? Notify everyone when a new media is uploaded?

Thanks to Aquarium action system, you can create this automation. In this tutorial, we will show you how to create a Discord webhook and how to use it to send notifications to your team.
